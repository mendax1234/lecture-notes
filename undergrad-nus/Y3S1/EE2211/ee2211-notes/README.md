# Welcome

Let's start by telling the truth: machines don't learn. What a typical "learning machine" does, is finding a **mathematical formula**, which, when applied to a collection of inputs (called "training data"), produces the desired outputs. This mathematical formula also generates the correct outputs for most other inputs (distinct from the training data) on the condition that those inputs come from the same or a similar statistical distribution as the one the training data was drawn from.

Why isn't that learning? Because if you slightly distort the inputs, the output is very likely to become completely wrong. So why the name "machine learning" then? The reason, as is often the case, is **marketing**.

As you can see, just like artificial intelligence is not intelligence, machine learning is not learning. However, machine learning is a universally recognized term that usually refers to the science and engineering of building machines capable of doing various useful things **without being explicitly programmed to do so**. Arthur Samuel came up with the following definition of machine learning based on the previous very very important sentence.

> Machine Learning is a field of study that gives computers the ability to **learn** without being explicitly programmed to do so.

The keyword here is "learn", by which it means the computer can learn "something" that is **not manually defined**.

Thus, to differentiate machine learning applicaiton with other borad AI applications, we will use the term "learn" to see if the system indeed learned something "new"!
