### 2. Feedback Amplifier

When the question specifies that the feedback coefficient $$\beta$$ is independent of frequency, this means that our feedback transfer function is a constant. In other words, the feedback path only contains resistor. An example if given in [Lec 10](../lec/lec-10-frequency-response-part-2.md#finding).
