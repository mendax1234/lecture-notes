According to Prof. Colin, there are **two key takeaways** from this course:

1. **ARM Programming**
2. **The OS is nothing speical but just a program.** It does not run continuously in the background; when a process is running, the OS is not executing on the CPU. The OS regains control through **system calls, interrupts, or exceptions**, allowing it to perform tasks such as scheduling processes and managing resources.
